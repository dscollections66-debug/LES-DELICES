# Les Délices de FA — site web

- Le site : `index.html` (une seule page, sans compilation).
- Le contenu : dossier `data/` (produits et formats, prix, stock, crèmes, textes, photos, avis).
- Les photos des produits : `images/produits/`.
- Les illustrations des étiquettes : `images/ill-*.jpg`.

Le portail de Fa (gestion du stock et des prix) viendra modifier les fichiers de `data/`.
